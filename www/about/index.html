What does the homelab stack do?

At a high level, this environment is a secure, containerized private cloud designed to bridge low-power, high-efficiency hardware with modern edge routing.

The architecture achieves secure public service delivery and strict local privacy by leveraging Cloudflare Tunnels and an Nginx reverse proxy. That combination securely exposes web services and game server entry points to the public internet while hiding the underlying home IP address and eliminating open inbound ports.

Behind that protective edge layer is an orchestrated compute environment across a multi-node Raspberry Pi cluster. Running Docker Engine, that layer isolates and manages diverse workloads ranging from gaming infrastructure to local large language models through Ollama AI and automated data-scraping scripts.

Local network security and administrative access are handled through a Pi-hole DNS sinkhole paired with an upstream Unbound recursive DNS resolver, alongside WireGuard for encrypted remote administration. In practice, that means the stack is built to be usable from anywhere without becoming careless about exposure.

The ecosystem is anchored by persistent shared storage on a Samba-configured HDD, which provides centralized file sharing and stateful storage for the containerized services that live across the stack.

Why the night ocean theme?

I chose the night ocean theme because to me it represents the human experience: everything above and everything below.

There is a rare peace found only on a dark, glassy ocean, where the horizon fades and you are suspended between two vast wildernesses. When the sea is calm and the night is clear, the ocean and the sky cease to be separate things.

The stars above represent our highest ambitions; the depths below, our quiet resilience. Between the two lies absolute clarity.
